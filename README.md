## 🚀 Installation

### 1. Download anyL
Download the latest `anyL.exe` from [anyl.app/files/anyL.exe](https://anyl.app/files/anyL.exe) or from the [Releases](https://github.com/anyLapp/anyL/releases) page.

### 2. Install Tesseract OCR
anyL uses Tesseract for text recognition. Download and install it from:
👉 [github.com/tesseract-ocr/tesseract/releases](https://github.com/tesseract-ocr/tesseract/releases)

> **Important:** During installation, select **German** and **English** under "Additional language data".

Default path: `C:\Program Files\Tesseract-OCR\tesseract.exe`

### 3. Launch & Log in
Double-click `anyL.exe`, log in or register for free at [anyl.app](https://anyl.app).

## ⌨️ Hotkeys

| Key | Action |
|-----|--------|
| `F6` | Scan once & translate |
| `F7` | Start / stop Auto-Scan |
| `F8` | Show / hide overlay |

> All hotkeys can be customized in **Settings → Hotkeys**.
